A pump.fun replay bot for the 24-hour paper window: it buys a fresh curve only after a crowd of distinct buyers and eight SOL of net inflow are still there on a second look, cuts losers at nine percent, trails winners, and drips tiny probe round trips to stay over the twenty-coin guardrail bar.

## Run it

```sh
# The bot speaks agent-fun/replay/v2 JSON lines on stdin/stdout.
# The make.fun competition kit runs it locally against the dev window:
node cli/makefun.mjs grade-local --kit . --bot <this repository> --driver process
```
